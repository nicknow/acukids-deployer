# AI contributor resources

This directory contains reusable guidance for AI contributors. It answers
“How should an AI agent work in this repository?” Canonical information about
the software belongs in [`docs/`](../docs/README.md), which answers “How does
the software work?”

- `prompts/` contains reusable task prompts.
- `standards/` contains agent-specific contribution standards.
- `workflows/` contains repeatable agent procedures.
- `scratch/`, `cache/`, and `logs/` are ignored temporary storage.

Do not duplicate project architecture or operations here. Link to the canonical
documentation instead.
